1. Classical logic and semantic tableaux (L1, L2)

A classical model is just the set of variables that are true. A formula is valid (⊨ φ) if it is true in every model. Cl is the set of all valid formulas (tautologies). Truth tables decide this, but they need 2ⁿ rows.

The semantic tableau is a smarter search for a countermodel. A tableau is a pair t = (Γ, Δ): Γ is what we want true, Δ is what we want false. Start with (∅, {φ}) and break formulas apart:

RuleIf this is in……then add
S1ψ ∧ χ ∈ Γ (and is true)ψ and χ to Γ
S2ψ ∧ χ ∈ Δ (and is false)ψ to Δ or χ to Δ (branch)
S3ψ ∨ χ ∈ Γψ to Γ or χ to Γ (branch)
S4ψ ∨ χ ∈ Δψ and χ to Δ
S5ψ → χ ∈ Γψ to Δ or χ to Γ (branch)
S6ψ → χ ∈ Δψ to Γ and χ to Δ

A branch is closed when some formula sits on both sides, or ⊥ sits on the left. The tableau is disjoint if Γ ∩ Δ = ∅ and ⊥ ∉ Γ. Saturated means every rule has been applied. If every branch closes, φ is valid. If a branch stays open and saturated, its variables on the left give a countermodel.

Exam method · classical tableau

Example from L2: is Peirce's law ((p → q) → p) → p valid?

  1. Put it on the right: Δ = {((p→q)→p)→p}.
  2. S6 on that implication: Γ gets (p→q)→p, Δ gets p.
  3. S5 on (p→q)→p ∈ Γ branches. Left branch: p→q to Δ, then S6 gives p to Γ and q to Δ. Now p is in Γ and in Δ: closed.
  4. Right branch: p to Γ. p is already in Δ: closed.
  5. All branches closed, so no countermodel exists: Peirce's law ∈ Cl.

2. Hilbert calculus, derivations and ⊢ (L3 to L6)

A Hilbert calculus proves formulas from axioms with rules. The classical calculus CL has axioms A1 to A10 and two rules.

AxiomFormulaPlain meaning
A1p₀ → (p₁ → p₀)A true thing follows from anything.
A2(p₀→(p₁→p₂)) → ((p₀→p₁) → (p₀→p₂))Distribute an assumption.
A3, A4p₀ ∧ p₁ → p₀, p₀ ∧ p₁ → p₁Take a conjunct out.
A5p₀ → (p₁ → p₀ ∧ p₁)Build a conjunction.
A6, A7p₀ → p₀ ∨ p₁, p₁ → p₀ ∨ p₁Build a disjunction.
A8(p₀→p₂) → ((p₁→p₂) → (p₀∨p₁ → p₂))Proof by cases.
A9⊥ → p₀From false, anything.
A10p₀ ∨ (p₀ → ⊥)Excluded middle. Int drops this one.

Rules: MP (modus ponens): from φ and φ → ψ get ψ. Subst: from φ get any substitution instance (replace variables uniformly by formulas, e.g. p₀ := q ∧ r everywhere).

Γ ⊢ φ means φ is derivable when the formulas in Γ may be used as extra assumptions. Subst is applied only to axioms, never to assumptions (otherwise from p you could "derive" q).

Deduction theorem (L4)

Γ, ψ ⊢ φ implies Γ ⊢ ψ → φ. You may move an assumption to the left of an arrow ("discharge" it).

Soundness and completeness of CL (L5)

⊢ φ iff ⊨ φ. So Cl = {φ : ⊢ φ}: "provable" and "valid" give the same set.

From L6: a logic is any set of formulas closed under MP and Subst. A logic is consistent if it is not the set of all formulas (with A9 present, this is the same as ⊥ not being in it). L₂ is an extension of L₁ if L₁ ⊆ L₂. Cl is consistent, decidable, and Post complete (no consistent proper extension).

Common confusion · ⊨ versus ⊢

⊨ is about truth (models, worlds, valuations). ⊢ is about proofs (axioms and rules). Completeness theorems are exactly the bridges saying the two agree.

3. Intuitionistic Kripke models (L7, L8)

Picture it

Think of points as stages of knowledge over time, and R as "later stage". Once you have proved something you never lose it. A statement is "false now" only in the weak sense "not yet established".

An intuitionistic frame is 𝔉 = ⟨W, R⟩ where R is a partial order: reflexive (xRx), transitive (xRy, yRz ⇒ xRz) and antisymmetric (xRy, yRx ⇒ x = y). A valuation V must be upward closed: if x ∈ V(p) and xRy then y ∈ V(p). The set of upward closed subsets is written Up W. A model is 𝔐 = ⟨𝔉, V⟩.

FormulaTrue at x iff
px ∈ V(p)
⊥never
ψ ∧ χ / ψ ∨ χboth true at x / at least one true at x
ψ → χfor every y with xRy: if ψ true at y then χ true at y
¬ψψ is true at no y with xRy
Persistence (L7)

If x ⊨ φ and xRy then y ⊨ φ. Truth only spreads upward; falsity only spreads downward.

Truth in a model (𝔐 ⊨ φ): true at every point. Valid in a frame (𝔉 ⊨ φ): true at every point under every valuation. Int = the formulas valid in all intuitionistic frames. One-point frames behave classically, so Int ⊆ Cl.

Worked example (L8) · p ∨ ¬p and ¬¬p → p fail
  1. At b: p is true, so p ∨ ¬p is true.
  2. At a: p is false (a ∉ V(p)). ¬p is also false, because a sees b and p is true at b. So p ∨ ¬p is false at a.
  3. ¬p is false at a and at b. So no point above a makes ¬p true, which means ¬¬p is true at a.
  4. At a itself (aRa): ¬¬p true, p false. So ¬¬p → p fails at a.

The other direction p → ¬¬p is valid on every frame (by persistence).

Common confusion · → in Int

In classical logic and in modal logic (from L16 on), → only looks at the current point. In Int, → and ¬ look at all later points. This one difference is why p ∨ ¬p fails in Int.

4. Generated subframes and reductions (L8 to L10)

Subframe: pick a subset V ⊆ W and keep exactly the arrows between points of V. Generated subframe (𝔊 ⊑ 𝔉): a subframe whose V is upward closed (if x is in, everything x sees is in). The subframe generated by X is X↑, everything seen from X. A frame is rooted with root x if it is generated by {x}.

Generation theorem (L9)

If 𝔑 is a generated submodel of 𝔐, then for every x in 𝔑: 𝔑, x ⊨ φ iff 𝔐, x ⊨ φ. So 𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ for generated subframes, and Int = validity on all rooted frames.

Why: → and ¬ only look upward, and a generated subframe keeps everything above its points.

Picture it

A generated subframe is "x and its whole future". Throwing away points nobody above you can reach changes nothing for you.

A reduction (also called p-morphism) of 𝔉 = ⟨W, R⟩ onto 𝔊 = ⟨V, S⟩ is a map f : W → V that is onto and satisfies:

(R1) forth: xRy ⇒ f(x) S f(y)
(R2) back: f(x) S v ⇒ there is z with xRz and f(z) = v

𝔊 is then an f-reduct of 𝔉, and 𝔉 is reducible to 𝔊.

Picture it

A reduction glues points together without changing what anyone can "see". R1: you can't lose a view. R2: you can't gain a view you didn't already have in the original.

Reduction theorem (L10)

If f reduces model 𝔐 to model 𝔑 (with V(p) = f⁻¹(u(p))), then 𝔐, x ⊨ φ iff 𝔑, f(x) ⊨ φ. Consequence: 𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ for every reduct 𝔊. A one-to-one reduction is an isomorphism, and composing two reductions gives a reduction.

Exam method · finding reducts of a finite Int frame
  1. Write the up-set x↑ of every point. Make R reflexive and transitive first if the question lists it without the closure (say so in your answer).
  2. Rule for gluing: in a partial order, a reduction must satisfy f(x↑) = f(x)↑. So two points x, y can be glued only if their up-sets land on the same set of glued classes.
  3. Consequences you use all the time: final points (seeing only themselves) must go to final points. A point and a point strictly above it can be glued only if everything the lower one sees is glued into that same class or is also seen from the upper one.
  4. Try candidate gluings from the top down (final points first), check R1 and R2 for each, and draw each resulting frame.
  5. Always list the trivial ones: the frame itself (f = identity) and the one-point frame (everything glued; works for every rooted frame).
Worked example (L10)

The slide says (a) reduces to (b), (c) 3-chain, (d) fork, (e) 2-chain, (f) one point, but not to (g).

  1. To the diamond (b): send r to the bottom, a₁ and b₁ to the two middle points, and glue a₂, b₂ together onto the top. Every view of a point in (b) is the image of a view in (a). R1 and R2 both hold.
  2. To the 3-chain (c): glue a₁ with b₁, and a₂ with b₂. To the fork (d): glue a₁ with a₂, and b₁ with b₂. To the 2-chain (e): r to the bottom, everything else to the top. To (f): everything to one point.
  3. Why not (g): r must go to g's bottom (it sees everything, and f is onto). Some point must go to the middle m. By R2 it then needs two successors mapped to the two incomparable tops. In (a) only r has two incomparable successors, and r is already used. a₁ and b₁ each see only a chain. So no reduction exists.

5. Trees, unravelling, disjoint unions (L11, L12)

A tree is a rooted frame where every x↓ is finite and linearly ordered (no point is reached from two incomparable points). Unravelling theorem: every rooted frame is a reduct of a tree (points of the tree are paths from the root, f sends a path to its last point). 𝔗ₙ is the full n-ary tree (every point has exactly n immediate successors, no end). Every finite rooted frame is a reduct of 𝔗ₙ for n ≥ 2, so Int = {φ : 𝔗ₙ ⊨ φ}.

A disjoint union puts frames side by side with no arrows between them. Each piece is a generated subframe, so the union validates φ iff every piece does.

Picture it · the three "truth preserving operations"

Generated subframes (cut off the past), reductions (glue look-alike points), disjoint unions (put frames side by side). None of them can break the validity of a formula. These come back in lecture 18 and 19 for modal logic.

6. Int tableaux and Hintikka systems (L13)

To test φ ∈ Int, try to build a countermodel. Each point carries a tableau (Γ | Δ). In Int the rules S1 to S5 apply inside a point, but S6 is dropped: a false implication needs a new later point.

(HS_I1) if t S t′ then Γ ⊆ Γ′ (true things stay true later)
(HS_I2) if ψ → χ ∈ Δ then some t′ with t S t′ has ψ ∈ Γ′ and χ ∈ Δ′

A Hintikka system is a set of disjoint saturated tableaux with a partial order S satisfying HS_I1 and HS_I2. A tableau is realizable if some point of some model makes Γ true and Δ false. t is realizable iff there is a Hintikka system for it, and you never need more than 2|Σ| tableaux (Σ = subformulas). So Int has the finite model property: every non-theorem fails in a finite frame.

Exam method · "is φ ∈ Int?" by tableau
  1. Start at t₀ with φ on the right.
  2. Apply S1 to S5 inside the point. A true implication on the left (S5) branches: premise false or conclusion true.
  3. For every implication or negation on the right, open a new point above with the premise on the left and the conclusion on the right. Copy everything on the left of the lower point to the new point (HS_I1).
  4. If every attempt closes (a formula on both sides, or ⊥ on the left), φ ∈ Int. If you finish with no clash, read off the frame: points = tableaux, R = the arrows plus reflexive and transitive closure, V(p) = points with p on the left. Check V is upward closed.
  5. Verify the countermodel in two lines at the end. Examiners like seeing the check.
Worked example (L13) · Dummett's formula (p → q) ∨ (q → p)
  1. t₀: right side gets (p→q) ∨ (q→p). By S4 both disjuncts go right: p→q and q→p.
  2. p→q on the right: new point t₁ above t₀ with p | q.
  3. q→p on the right: new point t₂ above t₀ with q | p.
  4. No clash anywhere. Frame: t₀ below t₁ and t₂, which are incomparable. V(p) = {t₁}, V(q) = {t₂}.
  5. Check: t₁ ⊨ p, t₁ ⊭ q, so t₀ ⊭ p → q. t₂ ⊨ q, t₂ ⊭ p, so t₀ ⊭ q → p. So t₀ ⊭ (p→q) ∨ (q→p): not in Int.

A second slide example, p₂ ∨ (p₂ → p₁ ∨ ¬p₁), needs a 3-point chain t₀ R t₁ R t₂ with V(p₂) = {t₁, t₂}, V(p₁) = {t₂}.

Common confusion · when to open a new point

Only for an implication (or negation) on the right. Disjunctions and conjunctions are handled inside the same point. And remember to copy the left side upward: forgetting HS_I1 is the most common way to get a "countermodel" that is wrong.

7. Int formulas and frame conditions (L14)

Some formulas are valid exactly on frames with a certain shape. This is the Int version of what lecture 21 does for modal logic.

FormulaValid exactly on frames that are…
dₐ = (p→q) ∨ (q→p)strongly connected: xRy ∧ xRz ⇒ yRz ∨ zRy (any two points above x are comparable)
wem = ¬p ∨ ¬¬pstrongly directed (convergent): xRy ∧ xRz ⇒ some u with yRu and zRu

The valuation trick from the slides: to refute dₐ when y and z are incomparable above x, take V(p) = y↑ and V(q) = z↑.

Self-check

Why must an Int valuation be upward closed?

Because a point is a stage of knowledge. Something established at x stays established at every later stage. This is what gives persistence for all formulas.

Which classical axiom is missing from Int?

A10, excluded middle p₀ ∨ (p₀ → ⊥). Int is A1 to A9 with MP and Subst.

A map f is onto and satisfies R1 but not R2. Is it a reduction? What can go wrong?

No. Without R2 the image can contain views that the original point did not have, so a formula like ¬p could be true at x but false at f(x).

In an Int tableau, which formulas force you to create a new point?

Implications and negations on the right side (false ones). Everything else is decomposed inside the same point.

Lecture 16

The modal language, frames and models

Modal logic adds two words to classical logic: "necessarily" (□) and "possibly" (◇). The semantics reuses Kripke frames, but now R can be any relation.

The language

Take the propositional language and add one new rule: if φ is a formula, so is □φ. Then ◇φ := ¬□¬φ. Box and diamond bind more tightly than ∧, ∨, →, so □p → □q ∨ □r means (□p) → ((□q) ∨ (□r)).

Picture it

Each point is a city and R is the flight map. □φ at x: "every city I can fly to directly has φ". ◇φ at x: "at least one city I can fly to directly has φ". You don't look at your own city unless there is a loop flight (xRx).

Common confusion · Int versus modal

Three differences to keep straight:

  • Int: R is a partial order. Modal: R is anything (no loops needed, no transitivity).
  • Int: V(p) must be upward closed. Modal: V(p) is any set.
  • Int: → and ¬ look at later points. Modal: → and ¬ are classical (only the current point). Only □ and ◇ look elsewhere.

Satisfied, true in a model, refuted, valid in a frame and isomorphism all mean exactly what they meant for Int. In particular 𝔉 ⊨ φ (valid in the frame) means true at every point under every valuation.

Modal degree

md(p) = 0, md(ψ ⊙ χ) = max(md ψ, md χ) for ⊙ ∈ {∧, ∨, →}, and md(□ψ) = md(◇ψ) = md(ψ) + 1.

Examples: md(p ∧ q) = 0, md(□p → □□q) = 2, md(□(□p → p) → □p) = 2, md(□p → ◇p) = 1.

n-step accessibility and point types

x↑ⁿ is the set of points reachable from x in exactly n arrows. So x↑⁰ = {x} and x↑¹ = x↑.

  • If R is transitive: xRⁿy ⇒ xRy (collapse the path). If R is also reflexive, the converse holds too (pad the path with loops).
  • x is reflexive if xRx (then xRⁿx for every n). A frame is reflexive / irreflexive if all its points are.
  • A frame is intransitive if xRy ∧ yRz ⇒ ¬xRz always. This is stronger than "not transitive": it says no two-step path has a shortcut. An intransitive frame is automatically irreflexive (take x = y = z).

Self-check

Is ◇ a new primitive symbol?

No. ◇φ is shorthand for ¬□¬φ: "not every successor has ¬φ", i.e. some successor has φ.

md(◇(p ∧ □q) ∨ □r) = ?

max(1 + max(0, 1), 1) = 2.

Can a modal valuation make p true at x and false at a point x sees?

Yes. There is no persistence requirement in modal logic.

Lecture 17

Reading modal formulas on concrete models

This lecture is mostly practice: how to evaluate □, ◇, □ⁿ at a point, what happens at dead ends, and four examples that every later lecture refers back to.

Symbols in this chapter

SymbolMeaning
dead endA point with no successors at all (x↑ = ∅).
∘, •Reflexive point, irreflexive point.
LaLöb's formula □(□p → p) → □p.
induced subframe / submodelKeep a set X of points, all arrows between them, and V(p) ∩ X. X need not be upward closed.

Boxes and diamonds n levels deep

Proposition

x ⊨ □ⁿψ iff ψ is true at every point of x↑ⁿ. x ⊨ ◇ⁿψ iff ψ is true at some point of x↑ⁿ.

If x↑ⁿ = ∅ (no path of length n), then □ⁿφ is true (nothing to check) and ◇ⁿφ is false (no witness), for every φ.

Common confusion · dead ends

At a dead end, □φ is true for every φ, even □⊥, and ◇φ is false for every φ, even ◇⊤. "All of nobody" is vacuously true; "some of nobody" is false. Many countermodels in this course are just a dead end.

Proposition · only n steps matter

If md(φ) ≤ n, then whether φ is true at x depends only on the submodel induced by x↑⁰ ∪ x↑¹ ∪ … ∪ x↑ⁿ.

Why: each box or diamond moves you one step. A formula with at most n nested modalities never walks more than n steps away.

Drawing conventions

  • Irreflexive points are bullets •, reflexive points are circles ∘.
  • An arrow from x to y is drawn when x ≠ y and xRy.
  • Diagrams are assumed transitive: the shortcut x → z is not drawn if x → y → z is drawn. For a non-transitive frame, the lecture says so and draws every arrow.
  • In models, true formulas go on the left of a point and false ones on the right.
Common confusion · implied arrows

When a frame is "transitive by convention", a point sees everything above it along any path, even without a drawn arrow. When it is stated to be non-transitive, it sees only what is drawn. Always check which case you are in before evaluating □□p.

The four examples

Exam method · evaluating a formula at a point
  1. List the successors of the point (and theirs, if the formula has □□ or ◇◇).
  2. Evaluate from the inside out: atoms first, then □/◇ of atoms at each relevant point, then the outer connective.
  3. For a countermodel to α → β at x, show α true at x and β false at x.

Example 1 · single irreflexive point

  1. a has no successors, so a ⊨ □p (vacuous).
  2. p is false at a. So a ⊭ □p → p.
  3. ◇p needs a successor, there is none, so a ⊭ ◇p. With a ⊨ □p: a ⊭ □p → ◇p.

Both the T-axiom □p → p and the D-axiom □p → ◇p fail on a dead end.

Example 2 · single reflexive point, and Löb's formula

  1. a sees itself and p is false at a, so a ⊭ □p. Then □p → p and □p → ◇p are both true at a (false premise).
  2. For La = □(□p → p) → □p: the only successor of a is a, and a ⊨ □p → p (step 1). So a ⊨ □(□p → p).
  3. But a ⊭ □p. Premise true, conclusion false: a ⊭ La.

Example 3 · La on an infinite chain

  1. Every point has a successor where p is false, so □p is false everywhere.
  2. So □p → p is true everywhere (false premise), hence □(□p → p) is true everywhere.
  3. But □p is false everywhere, so La fails at every point.

Example 4 · transitivity axiom fails on a non-transitive frame

  1. Left frame: a's only successor is b and b ⊨ p, so a ⊨ □p.
  2. b's only successor is c and c ⊭ p, so b ⊭ □p. Since aRb, a ⊭ □□p.
  3. So a ⊭ □p → □□p.
  4. Reflexive variant: a's successors are a and b, both have p, so a ⊨ □p. b's successors are b and c, and c ⊭ p, so b ⊭ □p and a ⊭ □□p. Same conclusion.

Transitive frames: □ goes up, ◇ goes down

Proposition

On a transitive frame: (i) x ⊨ □φ and xRy ⇒ y ⊨ □φ. (ii) x ⊨ ◇φ and yRx ⇒ y ⊨ ◇φ.

Why: y's successors are also x's successors (transitivity), so whatever holds at all of x's successors holds at all of y's.

Picture it

This is the modal cousin of Int persistence, but weaker: it holds only for formulas that start with □ (upward) or ◇ (downward), and only on transitive frames.

Self-check

Is □⊥ true anywhere?

Yes: exactly at dead ends. That is a handy way to say "x is a dead end" in the language.

Why does Example 4 need the frame to be non-transitive?

□p → □□p is valid exactly on transitive frames (lecture 21). The countermodel uses aRb, bRc without aRc.

Does La fail on a single reflexive point, a single irreflexive point, or both?

Only the reflexive one. On a single irreflexive point □p is true (dead end), so La's conclusion holds.

Clusters, skeletons and generated sets

In a transitive frame some points see each other both ways. Such a group behaves like one "super point" for □ and ◇. Collapsing each group gives the skeleton.

Clusters

Definition

Let 𝔉 be transitive. Put x ∼ y iff x = y or (xRy and yRx). This is an equivalence relation; its classes are clusters, written C(x).

Picture it

A cluster is a group of friends who can all reach each other. Inside the group everyone sees the same "outside world", so nobody in the group can be told apart by □ or ◇ formulas.

Proposition

On a transitive frame, for every y ∈ C(x): x ⊨ □φ iff y ⊨ □φ, and x ⊨ ◇φ iff y ⊨ ◇φ. (Atoms can still differ inside a cluster.)

Why: if xRy and yRx, transitivity gives x and y exactly the same successors.

Three types of clusters

A reflexive and transitive relation is a quasi-order (also called preorder).

Common confusion · irreflexive points

An irreflexive point x does not see itself, but x ∼ x still holds because of the "x = y" clause. So it forms its own cluster {x}, the degenerate one. Points in a proper cluster are automatically reflexive (xRyRx gives xRx).

The skeleton (quotient frame)

Definition

For a transitive 𝔉, the quotient frame or skeleton is ρ𝔉 = ⟨W/∼, R/∼⟩ with C(x) R/∼ C(y) iff xRy. The skeleton is always antisymmetric. If R is reflexive (a quasi-order), the skeleton is a partial order.

Exam method · build the quotient and name the clusters
  1. Check transitivity first, because clusters are defined for transitive frames. If R is not transitive, say so and work with its transitive closure (add the missing shortcut pairs, and list them).
  2. Find all pairs with xRy and yRx, x ≠ y. Merge them into groups.
  3. Every point not merged is its own cluster: simple if xRx, degenerate if not. Merged groups are proper.
  4. Write ρW = list of clusters. Write ρR: C(x) ρR C(y) iff xRy (one representative pair is enough). Include C ρR C exactly when the cluster is not degenerate.
  5. Draw it and state the shape (chain, fork, …) and whether it is a partial order.
Worked example (practice, my own)

W = {0, 1, 2, 3, 4, 5}. 0 is irreflexive and sees 1 to 5. The rest is reflexive and transitive with 1 ↔ 2, 3 ↔ 4, and 1, 2 → 3, 4 → 5.

  1. Transitive: yes (every path's shortcut is present).
  2. Mutual pairs: 1R2 and 2R1; 3R4 and 4R3. So {1, 2} and {3, 4} are proper clusters.
  3. 5 is reflexive and alone: simple cluster {5}. 0 is irreflexive and alone: degenerate cluster {0}.
  4. ρW = { {0}, {1,2}, {3,4}, {5} }. ρR: {0} → {1,2} → {3,4} → {5} plus the transitive shortcuts, and a loop on each cluster except {0}.
  5. The skeleton is a 4-element chain. It is not a partial order, because {0} is irreflexive (R was not reflexive at 0).

The McKinsey formula is not valid everywhere

  1. Each point sees a₁, where p is true, so ◇p holds at both points. Hence □◇p holds at both.
  2. Each point sees a₂, where p is false, so □p fails at both. Hence ◇□p fails at both.
  3. So □◇p → ◇□p fails at a₁ and a₂. With K_ML = {φ : valid in all frames}, we get ma ∉ K_ML.

Notice the cluster proposition at work: a₁ and a₂ disagree on p but agree on every □ or ◇ formula.

Up-sets in non-transitive frames

The three truth preserving operations (generated subframes, reductions, disjoint unions) come back in modal form. Since modal frames need not be transitive, "everything above x" needs care:

  • X↑ⁿ = points reachable from X in exactly n steps; X↑ω = union over n ≥ 1; X↑̲ω = X ∪ X↑ω.
  • Example from the slide: W = {a, b, c}, R = {(a,b), (b,c)}. Then a↑ = {b} (c is not a direct successor), the upward closure of a is {a, b, c}, and a↓ = ∅.
Definitions
  • The upward closed set generated by X is X↑̲ω.
  • x is a root of 𝔉 if the subframe generated by x is all of 𝔉. A non-transitive frame can have several roots (the slide's frame with a 2-point cluster {a, b} at the bottom has roots a and b).
  • The cluster generated by x is x↑̲ ∩ x↓̲: points you can reach and that can reach you.
  • In a transitive frame, x is a final point and C(x) a final cluster in X if x↑ ∩ X = C(x) ∩ X (nothing in X strictly above).
  • x is a last point and C(x) the last cluster in X if X ⊆ x↓̲ (everyone in X sees x).
  • X is a cover for Y if Y ⊆ X↓ (every point of Y sees some point of X).
Common confusion · x↑ in non-transitive frames

In Int (transitive) x↑ was "everything above x". In a non-transitive modal frame, x↑ is only the one-step successors. The full future is x↑̲ω.

Self-check

Can a cluster contain an irreflexive point together with other points?

No. If x is in a cluster with y ≠ x then xRy and yRx, so by transitivity xRx.

Why must you check transitivity before computing clusters?

The definition of ∼ is only an equivalence relation when R is transitive. Without it, x ∼ y and y ∼ z need not give x ∼ z.

The skeleton of a quasi-order is a ...?

Partial order (reflexive, transitive, antisymmetric).

Generation, reduction and trees for modal logic

The Int tools from lectures 9 to 11 carry over to modal frames, with small changes because R can now be anything.

Generation

Generation theorem

If 𝔑 is a generated submodel of 𝔐, then (𝔑, x) ⊨ φ iff (𝔐, x) ⊨ φ for every x in 𝔑.

Corollary. If 𝔊 ⊑ 𝔉 then 𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ. And K = {φ : 𝔉 ⊨ φ for all rooted 𝔉}.

Reduction

Same definition as Int (onto, R1 forth, R2 back), now for arbitrary relations.

Reduction theorem

If f reduces model 𝔐 to 𝔑 then (𝔐, x) ⊨ φ iff (𝔑, f(x)) ⊨ φ. Corollary: if 𝔉 reduces to 𝔊 then 𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ.

Worked example · reducing ⟨ℕ, <⟩
  1. f(n) = n mod 2 onto (b). Onto: f(0) = 0, f(1) = 1. Forth: in (b) everything sees everything, so R1 is automatic. Back: if f(n) sees v, choose m > n with m mod 2 = v (n+1 or n+2). Then n < m and f(m) = v.
  2. g(n) = 0 onto (c). Forth trivial. Back: g(n) sees 0, take m = n + 1.
  3. Without transitive closure (n sees only n+1): g still works, but f fails back. f(n) sees f(n) itself in (b), so n needs a successor of the same parity, and its only successor n+1 has the other parity.
  4. General fact: a reduction can never send a reflexive point to an irreflexive one (R1 on xRx gives f(x) S f(x)). The opposite direction is allowed, as here.
Proposition

If φ is valid in some frame, then φ is valid in ∘ or in •.

Why: if the frame has a dead end x, then {x} alone is a generated subframe, which is •. If it has no dead end, mapping every point to ∘ is a reduction (back works because every point has a successor).

Use it

To prove a formula is valid in no frame, it is enough to show it fails in ∘ and in •. Example: □p ∧ ◇¬p fails in ∘ (□p forces p at the only point, so ◇¬p is false) and in • (◇ of anything is false at a dead end).

Trees and unravelling

A modal frame is a tree if its reachability order R* is a tree partial order (rooted, every point has finitely many predecessors forming a chain). An intransitive tree is one where R links each node only to its immediate children.

Theorem

Every rooted modal frame is a reduct of some intransitive tree. Corollary: K = {φ : 𝔉 ⊨ φ for all intransitive trees 𝔉}.

Construction in one line: points of the tree are finite paths ⟨v₀, v₁, …, vₙ⟩ from the root; a path sees its one-step extensions; f sends a path to its last point.

Picture it

Unravelling is like writing down every possible journey from home. A city visited twice by different routes becomes two separate tree nodes, but the "last city" map glues them back.

The Bulldozer theorem

Theorem

(i) Every transitive frame is a reduct of a strict partial order frame. (ii) Every quasi-order frame is a reduct of a partial order frame.

Idea: replace every non-degenerate cluster by infinitely many copies of its points, ordered in a long strictly increasing line ("bulldozing" the cluster flat). Degenerate clusters need only one copy. Mapping each copy back to its original is a reduction.

Why it matters: clusters can always be "unfolded" without changing which formulas are valid. So K4 can be studied on strict partial orders and S4 on partial orders.

Self-check

Can ∘ be reduced onto •?

No: the reflexive point would have to map to an irreflexive one, which breaks R1.

Why does ⟨ℕ, <⟩ validate □p → ◇p?

Every n sees n+1, so □p true at n gives p at n+1, hence ◇p at n. (The frame is serial: no dead ends.) Careful: reductions only carry validity from 𝔉 to its reduct, never back, so "it reduces to ∘" alone would not prove this.

What does the generation corollary let you assume when hunting for a countermodel?

That the frame is rooted at the point where the formula fails.

The two modal rules

(HS_M1) if t S t′ and □ψ ∈ Γ, then ψ ∈ Γ′ (a true box is copied into every successor)
(HS_M2) if □ψ ∈ Δ, there is t′ with t S t′ and ψ ∈ Δ′ (a false box needs a witness successor)

A Hintikka system in K is a non-empty set T of disjoint saturated tableaux with a relation S satisfying HS_M1 and HS_M2. It is a Hintikka system for t if t ⊆ t′ for some t′ in T. A tableau is realized at x if everything in Γ is true at x and everything in Δ is false there; realizable in K if realized in some model.

Propositions

t is realizable in K iff there is a Hintikka system for t. A Hintikka system for (∅, {φ}) refutes φ.

Theorem · finite size

t is realizable in K iff there is a Hintikka system for t with at most 2|Σ| tableaux, Σ = all subformulas of formulas in t.

Why: from a model, take for each point x the tableau t_x = (formulas of Σ true at x | formulas of Σ false at x). It is determined by a subset of Σ, so there are at most 2|Σ| different ones.

Corollaries · finite model property

(i) Every φ ∉ K is refuted on a rooted frame with at most 2|Sub φ| points. (ii) Every φ ∉ K is refuted on a finite intransitive tree. So K = {φ : valid on all finite intransitive trees}.

Exam method · modal countermodel by tableau
  1. Put φ on the right of t₀. Apply S1 to S6 inside the point (→ on the right: premise left, conclusion right).
  2. For each □ψ on the right: make a new successor with ψ on its right.
  3. For each □χ on the left: put χ on the left of every successor. If the frame must be reflexive, also put χ on the left of the same point. If it must be transitive, also copy □χ itself to successors.
  4. Repeat until nothing new appears. Read off W, R and V(p) = points with p on the left. Then verify at t₀.

Example · countermodel for sc

  1. t₀ right: □(□p → q) ∨ □(□q → p). S4: both disjuncts go right.
  2. □(□p → q) on the right: successor t₁ with □p → q on the right, so □p left, q right.
  3. □(□q → p) on the right: successor t₂ with □q left, p right.
  4. The boxes at t₁, t₂ are on the left, so no new points. t₁ and t₂ are dead ends.
  5. Check: t₁ ⊨ □p (dead end), t₁ ⊭ q, so t₁ ⊭ □p → q and t₀ ⊭ □(□p → q). Symmetrically t₀ ⊭ □(□q → p). So t₀ ⊭ sc.
  6. Gluing t₁ and t₂ into one dead end t (□p, □q | p, q) gives a smaller countermodel.

Example · countermodel for grz, then a reflexive one

  1. Any frame: t₀ right gets grz, so □(□(p → □p) → p) left and p right. The box is on the left, so no successor is required. One irreflexive point with p false refutes grz.
  2. Reflexive frame required: the left box also puts □(p → □p) → p on the left of t₀ itself. S5: p can't go left (clash), so □(p → □p) goes right.
  3. That false box needs t₁ with p → □p on the right: p left, □p right.
  4. □p false at t₁ needs t₂ with p right.
  5. Frame: t₀ → t₁ → t₂, each reflexive, no t₀ → t₂. V(p) = {t₁}.
  6. Check: t₁ ⊭ □p (t₂ has no p), so t₁ ⊭ p → □p, so t₀ ⊭ □(p → □p), so □(p→□p) → p is true at t₀; at t₁ it is true because p is. So t₀ ⊨ □(□(p → □p) → p), t₀ ⊭ p: grz fails.
Common confusion · which side triggers what

Box on the right (false) creates a successor. Box on the left (true) never creates anything, it only fills in existing successors. Mixing these up is the classic tableau error. (In Int tableaux the trigger was an implication on the right.)

Self-check

Why are all six rules S1 to S6 allowed inside a modal point, but only S1 to S5 in Int?

Modal → is classical (it looks only at the current point). In Int, a false implication needs a later point, so S6 is replaced by HS_I2.

What is the size bound for a countermodel of φ ∉ K?

At most 2|Sub φ| points, on a rooted frame.

Why was transitivity dropped in the reflexive grz countermodel?

grz is valid on all finite partial orders, so a finite reflexive countermodel must break transitivity (or antisymmetry).

Correspondence theory: formulas and frame conditions

Many modal formulas are valid on a frame exactly when the arrows of the frame have some shape. Proving "𝔉 ⊨ φ iff 𝔉 has property P" is a standard exam question, and it always follows the same two-half recipe.

The recipe (memorise this)

Exam method · proving 𝔉 ⊨ φ ⟺ 𝔉 has property P

Half 1 (P ⇒ valid). Suppose 𝔉 has P, and suppose φ fails at some x under some valuation. Unfold what "φ false at x" forces (which points must exist, what is true where). Use P to reach a contradiction.

Half 2 (valid ⇒ P), by contrapositive. Suppose 𝔉 does not have P. Name the bad points that witness the failure. Choose a valuation V(p) that makes φ false at one of them. Then 𝔉 ⊭ φ.

How to pick V(p) in half 2:

  • p sits under a □ on the left of the arrow (like □p → …): make p true at exactly the points the box needs: V(p) = R(x) (x's successors), or V(p) = W ∖ {x}.
  • p appears bare or under a ◇ on the right: make p true at as little as possible, usually V(p) = {x}.

Reflexivity: ref = □p → p

Proposition

𝔉 ⊨ □p → p iff 𝔉 is reflexive (∀x xRx).

  1. Reflexive ⇒ valid. Suppose x ⊨ □p. Since xRx, x is one of its own successors, so x ⊨ p.
  2. Valid ⇒ reflexive (contrapositive). Suppose some x has ¬xRx. Put V(p) = W ∖ {x}.
  3. Every successor of x is different from x, so lies in V(p): x ⊨ □p. But x ∉ V(p): x ⊭ p. So x ⊭ □p → p.

Transitivity: tra = □p → □□p

Proposition

𝔉 ⊨ □p → □□p iff 𝔉 is transitive.

  1. Transitive ⇒ valid. Suppose x ⊨ □p, xRy, yRz. Transitivity gives xRz, so z ⊨ p. Hence every successor y of x has y ⊨ □p, so x ⊨ □□p.
  2. Valid ⇒ transitive. Suppose xRy, yRz but ¬xRz. Put V(p) = {w : xRw}.
  3. x ⊨ □p by the choice of V. z ∉ V(p), so y ⊭ □p, so x ⊭ □□p.

Symmetry: sym = p → □◇p (fully worked, it was on the past paper)

Proposition

𝔉 ⊨ p → □◇p iff 𝔉 is symmetric (∀x, y: xRy ⇒ yRx).

  1. Symmetric ⇒ valid. Take any valuation and any x. Suppose x ⊨ p; we must show x ⊨ □◇p.
  2. Take any y with xRy. By symmetry yRx. So y has a successor (namely x) where p is true: y ⊨ ◇p.
  3. y was arbitrary, so x ⊨ □◇p. Hence x ⊨ p → □◇p at every point: 𝔉 ⊨ sym.
  4. Valid ⇒ symmetric (contrapositive). Suppose 𝔉 is not symmetric: there are x, y with xRy and ¬yRx.
  5. Define V(p) = {x}. Then x ⊨ p.
  6. The only p-point is x, and y does not see x, so y ⊭ ◇p.
  7. Since xRy and y ⊭ ◇p, we get x ⊭ □◇p.
  8. So x ⊨ p and x ⊭ □◇p: x ⊭ p → □◇p, hence 𝔉 ⊭ sym. Both halves done. ∎
Picture it

p → □◇p says "if I am here, every place I can go has a road back to a p-place". Making only x a p-place forces "road back to x", i.e. symmetry.

Seriality: ser = □p → ◇p

Proposition

𝔉 ⊨ □p → ◇p iff 𝔉 is serial (∀x ∃y xRy, no dead ends).

  1. Serial ⇒ valid. If x ⊨ □p, pick a successor y (exists by seriality). y ⊨ p, so x ⊨ ◇p.
  2. Valid ⇒ serial. If x is a dead end, then under any valuation x ⊨ □p (vacuous) and x ⊭ ◇p (no witness).

The Geach family: one theorem covering most of these

Proposition

𝔉 ⊨ ◇ᵏ□ˡp → □ᵐ◇ⁿp iff ∀x, y, z (xRᵏy ∧ xRᵐz → ∃u (yRˡu ∧ zRⁿu)).

In words: go k steps from x to y and m steps from x to z; then y (in l steps) and z (in n steps) must be able to meet at a common u. For half 2 the slide uses V(p) = {u : yRˡu}.

Common confusion · RN

RN applies only to formulas you have derived (theorems). It never applies to assumptions: p ⊢ □p is false. If p is true here, that says nothing about other worlds. But if p is provable, it is true at every world, so □p is too.

Example 1 · the derived rule "from φ → ψ get □φ → □ψ"

  1. ⊢ φ → ψ (given)
  2. ⊢ □(φ → ψ) (RN on 1)
  3. ⊢ □(φ → ψ) → (□φ → □ψ) (A11 with Subst p₀ := φ, p₁ := ψ)
  4. ⊢ □φ → □ψ (MP on 2, 3)

Example 2 · □ distributes over ∧: ⊢ □(φ ∧ ψ) ↔ □φ ∧ □ψ

  1. ⊢ φ ∧ ψ → φ (A3) and so ⊢ □(φ ∧ ψ) → □φ (Example 1)
  2. ⊢ φ ∧ ψ → ψ (A4) and so ⊢ □(φ ∧ ψ) → □ψ (Example 1)
  3. ⊢ □(φ ∧ ψ) → □φ ∧ □ψ (combine 1 and 2 by classical reasoning)
  4. ⊢ φ → (ψ → φ ∧ ψ) (A5) and so ⊢ □φ → □(ψ → φ ∧ ψ) (Example 1)
  5. ⊢ □(ψ → φ ∧ ψ) → (□ψ → □(φ ∧ ψ)) (A11)
  6. ⊢ □φ → (□ψ → □(φ ∧ ψ)) (chain 4 and 5)
  7. ⊢ □φ ∧ □ψ → □(φ ∧ ψ) (from 6: (α → (β → γ)) gives (α ∧ β → γ))
  8. ⊢ □(φ ∧ ψ) ↔ □φ ∧ □ψ (3 and 7 joined with A5)

By induction this extends to n conjuncts: ⊢ □(φ₁ ∧ … ∧ φₙ) ↔ □φ₁ ∧ … ∧ □φₙ.

Common confusion · □ and ∨

□ distributes over ∧, but not over ∨. □(p ∨ q) → □p ∨ □q is not valid: a point seeing one p-world and one q-world has □(p ∨ q) but neither □p nor □q.

Soundness and completeness of K

⊢_K φ iff φ is valid in all frames. So K (calculus) = K (logic).

Intuitionistic versus superintuitionistic

Picture it

Int is one specific logic (A1 to A9). "Superintuitionistic" is a family: every logic you get by starting from Int and adding axioms. Int is the bottom of the family, Cl is the top consistent member, For (everything) sits above Cl.

Theorems
  • For is the greatest si-logic, Int the smallest.
  • Every consistent si-logic L satisfies Int ⊆ L ⊆ Cl.
  • The intersection of any family of si-logics is a si-logic.
  • For any class 𝒞 of intuitionistic frames, Log 𝒞 is a si-logic.

Examples: Cl = Int + p ∨ ¬p. For = Int + p (substitute ⊥ for p to get ⊥, then A9 gives everything). Strictly between them sits e.g. Int + ¬p ∨ ¬¬p: it proves weak excluded middle (so it is above Int), but not p ∨ ¬p (the 2-point chain with V(p) = {top} refutes p ∨ ¬p and validates ¬p ∨ ¬¬p, since that frame is strongly directed).

Building logics: +, finite axioms, sums

  • Finitely axiomatizable: L = Int + Γ with Γ finite. Since Int + φ₁ + … + φₙ = Int + φ₁ ∧ … ∧ φₙ (A3 to A5), one extra axiom is always enough.
  • Sum: (Int + Γ₁) + (Int + Γ₂) = Int + Γ₁ ∪ Γ₂. Just pool the axioms.
  • Extension of L with Γ: L + Γ, using L instead of Int as the base.
  • ⊢_L φ means derivable in L; φ ∈ L iff ⊢_L φ. Generalized deduction theorem: Γ, ψ ⊢_L φ iff Γ ⊢_L ψ → φ.

Intersections and the repeatless disjunction

Theorem

If L₁ = Int + {φᵢ} and L₂ = Int + {ψⱼ}, then L₁ ∩ L₂ = Int + {φᵢ ∨̲ ψⱼ}.

Worked example · why the variables must be renamed
  1. L₁ = Int + p = For. L₂ = Int + ¬p = For too (substitute p := ⊤, get ¬⊤, which gives ⊥). So L₁ ∩ L₂ = For.
  2. Correct (repeatless): p ∨̲ ¬p = p ∨ ¬q. Substitute p := ⊥, q := ⊤: ⊥ ∨ ¬⊤, which is Int-equivalent to ⊥. So Int + (p ∨ ¬q) = For. ✔
  3. Wrong (shared variable): Int + (p ∨ ¬p) = Cl ≠ For. ✘
Lattice laws

+ is idempotent (L + L = L), commutative, associative, and distributes over ∩; ∩ distributes over (infinite) sums. The family of si-logics with ∩ and + is the lattice ExtInt. If L ⊆ L′, L′ is an extension of L and L a sublogic of L′; ExtL is the family of L's extensions.

Modal side: quasi-normal versus normal

Definitions
  • Quasi-normal modal logic: K ⊆ L, closed under MP and Subst. Written L = K + Γ. Smallest: K. Greatest: For ML.
  • Normal: quasi-normal and also closed under RN. Written L = K ⊕ Γ.
Example · K + Γ and K ⊕ Γ really differ
  1. Let L = all formulas true at x under every valuation. L contains K, and is closed under MP and Subst, so it is quasi-normal.
  2. □⊥ → p ∈ L: x sees y, and y ⊭ ⊥, so x ⊭ □⊥; the implication is true at x.
  3. □(□⊥ → p) ∉ L: at y, □⊥ is true (dead end); with V(p) = ∅, p is false at y, so y ⊭ □⊥ → p, and x ⊭ □(□⊥ → p).
  4. So L is not closed under RN: quasi-normal but not normal.
Common confusion · + versus ⊕

+ closes under MP and Subst. ⊕ also closes under RN. All the named logics (T, K4, S4, S5, D) are built with ⊕, so they are normal.

Canonical models and completeness

How do you prove a logic L is complete (everything valid on its frames is provable)? Build one giant model out of L itself, where every non-theorem fails somewhere. That model is the canonical model.

The big idea

Picture it

A maximal consistent tableau is a complete description of a possible world that L cannot rule out: it says, for every formula, "true" or "false", without contradicting L. The canonical model puts all these descriptions together as its worlds. Then a formula is true at a world exactly when that world's description says so.

Completeness in contrapositive form: if L does not prove φ, find a countermodel. The canonical model provides one for every non-theorem at once.

The construction, step by step

Lindenbaum's lemma

Every L-consistent tableau can be extended to a maximal L-consistent tableau.

How: list all formulas φ₁, φ₂, …. Go through them one by one. Try putting φᵢ on the false side; if that would make the tableau inconsistent, put it on the true side. Consistency is kept at each step, and in the limit every formula is decided.

Key lemma

Λ ⊢_L φ iff φ ∈ Γ for every maximal L-consistent (Γ, Δ) with Λ ⊆ Γ. In particular φ ∈ L iff φ ∈ Γ for every maximal L-consistent (Γ, Δ).

Canonical frame. W_L = all maximal L-consistent tableaux, and for t₁ = (Γ₁, Δ₁), t₂ = (Γ₂, Δ₂):

L ∈ ExtInt: t₁ R_L t₂ iff Γ₁ ⊆ Γ₂ (iff Δ₁ ⊇ Δ₂)
L ∈ NExt K: t₁ R_L t₂ iff {ψ : □ψ ∈ Γ₁} ⊆ Γ₂
Picture it · the modal R_L

World t₂ is reachable from t₁ exactly when everything t₁ calls necessary is true in t₂. It is the most natural definition you could write.

Lemma

𝔉_L is a Hintikka system in Int (if L ∈ ExtInt) and in K (if L ∈ NExt K).

Canonical valuation V_L(p) = {(Γ, Δ) ∈ W_L : p ∈ Γ}, and 𝔐_L = ⟨𝔉_L, V_L⟩ is the canonical model.

Canonical model theorem (truth lemma)

For a consistent si-logic or normal modal logic L, every formula φ and every t = (Γ, Δ) in W_L:

(i) φ ∈ Γ ⇒ (𝔐_L, t) ⊨ φ   (ii) φ ∈ Δ ⇒ (𝔐_L, t) ⊭ φ   so (iii) (𝔐_L, t) ⊨ φ iff φ ∈ Γ.

Theorem

Every L-consistent tableau is realized in 𝔐_L. In particular Λ ⊢_L φ iff every point of 𝔐_L satisfying Λ satisfies φ, and φ ∈ L iff 𝔐_L ⊨ φ.

From the model to completeness

  1. If φ ∉ L, some world of 𝔐_L makes φ false. So the frame 𝔉_L refutes every non-theorem.
  2. If we also know 𝔉_L ⊨ L (L is valid on its canonical frame), then L = Log 𝔉_L: L is complete for this one frame.
  3. A logic with 𝔉_L ⊨ L is called canonical. Int and K are obviously canonical (every partial order validates Int; every frame validates K).
Theorem

Every canonical si-logic or normal modal logic is strongly Kripke complete (complete even with sets of assumptions).

Common confusion · model versus frame

"𝔐_L ⊨ L" (true in the one canonical model) is automatic from the truth lemma. "𝔉_L ⊨ L" (valid on the canonical frame under every valuation) is the extra thing you must prove. Canonical logics are exactly the ones where it holds.

The recipe, shown on T

Exam method · prove L is complete for the frames with property P
  1. Already known: L is sound for P-frames (L is valid on every P-frame).
  2. Show the canonical frame 𝔉_L has property P.
  3. Then 𝔉_L ⊨ L, so L is canonical and characterized by the P-frames.
Worked example · T = K ⊕ □p → p: the canonical frame is reflexive
  1. Suppose some t = (Γ, Δ) in W_T has not t R_T t.
  2. By the definition of R_T, some ψ has □ψ ∈ Γ but ψ ∉ Γ (so ψ ∈ Δ).
  3. □ψ → ψ is an instance of the axiom, so it is in T, hence in Γ (maximal consistent sets contain the logic).
  4. Γ contains □ψ and □ψ → ψ and is closed under MP, so ψ ∈ Γ. Contradiction with ψ ∈ Δ.
  5. So 𝔉_T is reflexive. Corollary: T is complete w.r.t. reflexive frames, and T is canonical.

The same style of argument shows: if □p → □□p ∈ L, 𝔉_L is transitive (□ψ ∈ Γ₁ gives □□ψ ∈ Γ₁, so □ψ ∈ Γ₂, so ψ ∈ Γ₃).

General theorem and corollaries

Every logic in ExtInt or NExt K axiomatized by formulas of the kind seen in lecture 21 is canonical, and its canonical frame satisfies the first-order condition matching its axioms. Hence:

  • K4 is characterized by transitive frames.
  • S4 by quasi-order frames.
  • S5 by frames with universal accessibility relation.
  • D by serial frames.
  • S4.3 by connected quasi-orders, and also by linear partial orders.
  • S5 is locally tabular (for each n, only finitely many formulas in n variables up to equivalence) and is characterized by finite universal frames.
